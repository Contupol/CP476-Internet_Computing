# CP476-Internet_Computing
A full-stack web application project for CP476-Internet Computing.
Uses a kanban board for tracking and planning project information.
There will be three milestones;
1. Due Jan 30th
2. Due Feb 27th
3. Due April 3rd

Information found in CP476 project description file.

# How to run index.js
- PREREQUISITES
  - Need node.js and MYSQL installed (and set up for PATH)
- in the terminal in the directory with the index.js file run 'node index.js'
- server will be running on <u>http://localhost:8000/index.php</u>
